# AURELIA — The Floating Isles

A vintage travel poster for a place that isn't there: **Aurelia**, a chain of
floating islands adrift above a bioluminescent sea, under an aurora sky and a
full moon. A striped lighthouse sweeps its beam across the drifting isles,
waterfalls spill off their rims into the glowing water below, and a lone
sailboat crosses the light.

> "Where the islands drift and the sea glows beneath the stars."

The poster is drawn programmatically (1024×1024) — twilight gradient sky,
stars, aurora ribbons, floating islands with pine forests, a lighthouse and a
domed pavilion, a bioluminescent sea, and a classic double-rule border with
gold corner ornaments.

## Run it

```sh
python3 main.py
```

This writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `./output` if unset).
`main.py` is Python stdlib only; `draw_poster.py` (Pillow) regenerates the
poster artwork from scratch.
